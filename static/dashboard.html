Endpoints disponibles para Odoo

            

              

                Los POST requieren la API key, ya sea como ?key=TU_API_KEY en la URL
                o header X-Api-Key (así es como los configura el Webhook nativo de Odoo).
              

              

                

                  
                    
MétodoEndpointPara qué sirveCampos que necesita

                  
                  
                    
POST/odoo/webhook/orden-confirmada
                      Se confirma una orden de venta — envía la plantilla presupuesto_2.
                      name/display_name, amount_total, partner_id

                    
POST/odoo/webhook/trabajo-listo-taller
                      Trabajo listo para retirar en el Taller (16 de julio 980) — plantilla trabajo_listo_taller.
                      sale_order_id (o la propia sale.order), partner_id

                    
POST/odoo/webhook/trabajo-listo-oficina
                      Trabajo listo para retirar en Oficina (9 de julio 194) — plantilla trabajo_listo.
                      sale_order_id (o la propia sale.order), partner_id

                    
POST/odoo/webhook/trabajo-listo
                      Versión genérica (sin sucursal) — texto libre, solo funciona dentro de la ventana de 24hs.
                      sale_order_id, partner_id

                    
POST/odoo/webhook
                      Genérico — compatibilidad con configuraciones anteriores.
                      name/display_name, partner_id, mensaje (opcional)

                    
POST/odoo/enviar
                      Envío directo de un mensaje de WhatsApp con texto libre.
                      telefono, mensaje, nro_orden (opcional)

                    
GET/whatsapp/plantillas
                      Debug — lista las plantillas de WhatsApp aprobadas en Meta.
                      —

                    
GET/sync-clientes
                      Fuerza la sincronización de clientes de Odoo (la misma que corre cada 24hs).
                      —

                    
GET/sync-tareas
                      Fuerza la sincronización de tareas de Odoo (la misma que corre cada 30min).
                      —

                    
GET/actualizar-precios
                      Recarga la lista de precios.
                      —
